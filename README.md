# Problem Solving with Programs 

This course will introduce students to the fundamentals of programming in Java. Students will learn how to write code to solve a variety of problems, including mathematical problems, text processing problems, and potentially some simple game development.

## Course Objectives

By the end of this course, students will be able to:

  * Write basic Java programs
  * Use variables, loops, and conditional statements
  * Develop simple algorithms

## Course Materials

  * Java Development Kit (JDK) 21 or later
  * An IDE (Integrated Development Environment) - examples include IntelliJ IDEA or VS Code
