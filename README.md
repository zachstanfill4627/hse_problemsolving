# Problem-Solving with Programs 

This course offers a unique deep dive into the world of problem-solving through the lens of programming. Over the 
semester, we'll tackle a few problems, which allows us to dedicate two weeks to each. You'll learn to dissect 
challenges, design solutions, and bring them to life using code and principles. Having the option to use modern 
programming languages or graphical coding tools to craft our solutions, we will explore different programming 
paradigms and discover the tools that best suit your style. We'll begin by mastering fundamental programming concepts, 
then transition to dissecting each problem with flowcharts and pseudocode. From simple mathematical calculators to data 
manipulation and automation, you'll gain practical experience in programming.

This isn't just about learning to code; it's about cultivating critical thinking and logical reasoning. You'll develop 
the skills to approach any challenge with a structured, analytical mindset – skills that extend far beyond the computer 
screen. Team up with your classmates, don't be afraid to make mistakes, and high-five each other when you crack the 
code! This course is all about building a problem-solving toolkit that will help you tackle challenges in school and 
life. Get ready to think in new ways, see problems from different angles, and discover the creative problem solver 
inside you.

This course is designed for anyone in the 8-12 grade level with any level of computer or programming experience. 
Although we will be coding, don’t shy away due to lack of experience, we will have plenty of resources explaining 
coding basics and join up in groups for some extra reinforcement with any troublesome points.

## Student Safety Disclaimer

We understand that internet safety is a top priority for parents. In this Introduction to Programming course, we take 
that concern seriously. Rest assured that students will not have any access to the internet during class time. All 
coding activities will be conducted on a secure, closed network using HSE-issued laptops. This controlled environment 
ensures that students can focus on learning programming fundamentals without external distractions or exposure to 
potentially inappropriate content.

Our curriculum is designed to be self-contained, with all necessary resources and materials provided within the closed 
network. This approach allows us to maintain a safe and focused learning environment while providing students with the 
hands-on experience and tools they need to develop their programming skills. We believe this balance between security 
and educational opportunity is essential for a successful learning experience.

Any and all questions regarding your student’s safety are welcomed and will be answered promptly.

Please reach out through HSE to schedule meetings or contact with me.

## Semester Topics:

  * WEEK       1: Class Introductions, Class Overview, Programming Overview, HelloWorld Application
  * WEEK       2: Introduction to Problem Solving Process, Brief Overview of Programming Basics
                    (Variables, Data Types,  Operations, Conditionals, Looping, and Algorithms)
  * WEEK  3 -  4: Problem - Finding the Max Number
  * WEEK  5 -  6: Problem - Simple Calculator (Addition, Subtraction, Multiplication, Division)
  * WEEK  7 -  8: Problem - Roman Numeral to Modern Numbers
  * WEEK  9 - 10: Problem - Sorting a List of Numbers
  * WEEK 11 - 12: Problem - Calculating the Fibonacci Sequence
